Comment s'abonner à Klinik

Klinik t'aide à apprendre la sémiologie pendant tes stages : fiches avec références, cas cliniques, QCM, mode concours et cartes de révision. Une partie est gratuite pour essayer. Pour tout débloquer, tu paies par NatCash et tu reçois un code d'accès.

Ouvrir Klinik

Ouvre Klinik dans Chrome (Android) ou Safari (iPhone), pas dans le navigateur intégré à WhatsApp. Il n'y a pas de compte à créer : ton accès reste enregistré dans le navigateur que tu utilises.

S'abonner, étape par étape

  1. Dans Klinik, touche Profil, puis Voir les offres et s'abonner.
  2. Choisis ta formule. L'application affiche le montant exact à payer.
  3. Ouvre NatCash et envoie exactement ce montant au numéro :
    509 4072 4822
  4. NatCash t'envoie un SMS avec un numéro de transaction. Garde ce SMS.
  5. Dans Klinik, écris ton nom, ton numéro WhatsApp (pour recevoir ton code) et le numéro de transaction. Touche Préparer ma demande.
  6. Touche Envoyer par WhatsApp (ou Envoyer par SMS). Si le bouton ne s'ouvre pas, touche Copier le message et colle-le dans WhatsApp ou dans un SMS au 509 4072 4822.
  7. Colas vérifie ton paiement et te répond avec un code qui commence par KLK-.
  8. Dans Klinik, au même endroit (Profil, Voir les offres), colle ton code à l'étape « Active ton code » et touche Activer. Tu peux coller tout le message reçu.
Ne paie pas deux foisLa vérification se fait à la main, ce n'est donc pas instantané. Si tu n'as rien reçu après quelques heures, écris ou appelle le 509 4072 4822 avec ton nom et ton numéro de transaction.

Questions fréquentes

Comment je sais que mon accès est actif ?

La pastille en haut de l'écran passe de « Gratuit » à « Abonné », et ton profil affiche la date de fin.

Mon code ne marche pas

Copie-le en entier, de « KLK- » jusqu'à la dernière lettre, sans rien changer. Si l'écran dit « expiré » ou « ne correspond plus », demande un nouveau code.

J'ai envoyé un autre montant

Le montant doit être au moins celui de la formule. S'il est plus petit, tu ne reçois pas de code : écris-nous pour compléter.

Puis-je l'utiliser sur un autre téléphone ?

Oui, pour ton propre usage : colle le même code sur l'autre téléphone. Il est personnel, ne le partage pas.

J'ai changé de téléphone ou effacé les données du navigateur

Ta progression est perdue, mais ton accès revient : colle de nouveau ton code. Garde le message qui le contient.

Mon abonnement est terminé

Les fiches payantes se verrouillent. Refais les étapes de paiement pour recevoir un nouveau code. Si tu te réabonnes depuis le même téléphone et le même navigateur, les jours qu'il te reste s'ajoutent.

Klinik voit-il mon code PIN NatCash ?

Non. Le paiement se fait dans NatCash, jamais dans Klinik.

Besoin d'aide ?

Écris ou appelle le 509 4072 4822 avec ton nom et, si tu as payé, ton numéro de transaction.

Retour à Klinik

Klinik est un outil pédagogique. Il ne remplace ni le jugement clinique, ni les protocoles de ton établissement, ni l'avis d'un professionnel qualifié. Les questions d'entraînement sont originales : ce ne sont pas des questions officielles de l'USMLE, de Kaplan ou d'un concours de résidence.
